# Security

If you find a security problem in Recued, please tell us privately. Do not
open a public issue.

- On GitHub: open this repo's **Security** tab and choose **Report a
  vulnerability**.
- By email: support@recued.com

Please include:

- the version you run (`recued --version`);
- what you found, and what someone could do with it;
- the steps that make it happen.

Do not send your 24-word recovery key, pairing codes, passwords or API keys.
We never need them to look into a report.

Fixes ship in a new release. The [changelog](./CHANGELOG.md) says what each
release changed.
